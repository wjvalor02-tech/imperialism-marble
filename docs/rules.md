# 제국주의 마블 — 게임 규칙 명세

### 2-1. 구성

| 항목 | 내용 |
|---|---|
| 인원 | 4개 제국(영국·프랑스·독일·미국) (국제은행 업무는 웹앱이 자동 처리 — 진행자 불필요) |
| 시작 자금 | 각 350만원 (밸런스 조정, 원본 500만원) |
| 주사위 | 2개 (밸런스 조정, 원본 1개) |
| 게임판 | 24칸 (모서리 4 + 변마다 5칸), 출발에서 시계방향 |
| 식민지 | 19곳 (아프리카 9, 아시아 5, 오세아니아 5) + 파쇼다 |
| 특수칸 | 출발, 에티오피아, 시암, 라이베리아, 중국의 반식민지화, 파쇼다 사건 |
| 황금열쇠 | 10장 (전쟁 2, 방어 2, 매각, 파괴, 착취, 무역대금 면제, 동맹, 대출) |
| 승리 | ① 다른 나라가 모두 파산하고 한 나라만 남으면 즉시 승리 ② 수업 타이머(기본 30분)가 끝나면 총자산 1위 승리 |
| 총자산 | 현금 + 보유 식민지 투자액(확보 가격 + 진행한 식민화 비용 합계) − 남은 대출 원금 |

### 2-2. 칸별 처리

| 칸 | 처리 |
|---|---|
| 출발 | 출발을 지날 때마다(1바퀴마다) 통행료 10만원을 국제은행에 낸다 |
| 주인 없는 식민지 | 가격을 내고 식민지로 확보할 수 있다(선택) |
| 내 식민지 | 이번 바퀴에 아직 개발하지 않았다면 다음 식민화 단계 1개 진행 가능(선택) |
| 출발 통과 (조정 규칙, 기본 켬) | 이번 바퀴에 아직 개발하지 않은 내 식민지를 골라 각각 1단계씩 개발 가능(선택). 관리 화면에서 끄면 원래대로 도착해야만 개발 |
| 남의 식민지 | 현재 단계의 무역대금을 소유국에 지불 |
| 에티오피아 | 커피교역 값 50만원 납부 |
| 시암 | 앞쪽으로 가장 가까운 자기 식민지로 이동(없으면 제자리), 이동한 칸을 처리 |
| 라이베리아 | 3턴 이동 불가. '벌칙 수행 완료'를 누르면 즉시 탈출(엉덩이로 이름쓰기) |
| 중국의 반식민지화 | '중국 공동 식민통치기구'에 20만원 납부 후 **황금열쇠를 뽑음** (조정 규칙, 원본은 납부만) |
| 파쇼다 사건 | 영국이 도착하면 게임 중 1회, 프랑스에 200만원을 주고 점령 가능(무역대금 50만원 — 밸런스 조정, 원래 가이드는 100만원). 그 외에는 황금열쇠 |

### 2-3. 식민지화 단계 (공통 틀)

| 단계 | 개발 비용 | 무역대금 |
|---|---|---|
| 0. 확보만 한 상태 | 식민지 가격 | 5만원 (밸런스 조정, 원래 2만원) |
| 1. 회사 설립 | 20만원 | 15만원 |
| 2. 농장 설립 | 30만원 | 25만원 |
| 3. 광산 개발(1개) | 50만원 | 40만원 |
| 4. 광산 개발(2개) | 50만원* | 80만원 |
| 5. 지역 특화 시설 | 지역별 | 지역별 |

\* 확정: 광산은 두 번 개발할 수 있다(각 50만원). 1단계씩 진행하므로 광산 2개까지 최소 4바퀴가 걸린다.

지역 특화 시설(5단계):

| 식민지 | 특화 시설 | 비용 → 무역대금 |
|---|---|---|
| 모로코 | 철광 | 70 → 130 |
| 이집트 | 수에즈 운하 운영 | 100 → 160 |
| 남아프리카 연방 | 다이아몬드 광산 | 90 → 150 |
| 알제리 · 인도차이나 | 광산 3개 | 50 → 100 |
| 콩고 · 가봉 | 고무농장 | 80 → 140 |
| 카메룬 | 커피농장 | 60 → 100 |
| 서아프리카 · 캐롤라인제도 | 보크사이트 광산 | 90 → 150 |
| 인도 | 아편농장 | 90 → 150 |
| 미얀마 | 대규모 농경지 | 80 → 140 |
| 오스트레일리아 · 뉴질랜드 | 대규모 목양지 | 80 → 140 |
| 필리핀 | 담배농장 | 80 → 140 |
| 인도네시아 | 후추농장 | 80 → 140 |
| 마셜제도 | 코코넛농장 | 80 → 140 |
| 리비아(예외) | 광산 1개 이후 농장 2개 → 농장 3개 | 30 → 60, 30 → 90 |

### 2-4. 황금열쇠 처리 방식(웹앱용 해석)

| 카드 | 웹앱 구현 |
|---|---|
| 전쟁(2장) | 보관 가능. 사용 시 200만원 지불 → 대상 식민지 소유국에 방어카드가 있으면 '방어 사용?' 질문. 방어하면 공격 실패(전쟁비용만 소모), 없으면 식민지와 개발 단계를 그대로 빼앗음 |
| 방어(2장) | 보관 가능. 공격받을 때만 사용, 사용 시 200만원 지불 |
| 식민지 매각 | 내 식민지 1곳을 은행에 매각. 매각가 = 가격 + 개발비 합계의 50%(가정, 설정 가능) |
| 중요시설 파괴 | 100만원 지불, 적국 식민지 1곳의 단계를 1 낮춤 |
| 착취 강화 | 즉시 300만원 획득 + 성찰 메모 팝업(아래 5-2) |
| 무역대금 면제 | 보관 가능. 남의 식민지 도착 시 '면제권 사용?' 질문 |
| 동맹 | 상대국 수락/거절. 2바퀴 동안 서로 무역대금 절반 |
| 대출 | 즉시 500만원, 이후 출발 통과 때마다 50만원 자동 상환(10회) |

모든 카드는 '1회 사용 후 소멸'(원본: 황금열쇠카드는 1회에 한해 사용).
