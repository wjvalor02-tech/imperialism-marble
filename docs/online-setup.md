# 모둠모드(온라인) 설정 방법

모둠모드는 선생님 기기(전자칠판)가 **방장**이 되어 게임을 계산하고, 학생 기기 4대가 방 코드로 접속해 자기 나라의 차례에만 버튼을 누르는 방식입니다.
기기끼리 메시지를 주고받는 데 **Supabase Realtime(무료)**을 씁니다. 데이터베이스 표는 만들지 않으며, 주고받는 것은 방 코드·나라·모둠 이름(선택)·게임 상태뿐입니다. 학생 개인정보는 다루지 않습니다.

> 설정 전에는 **시험 연결**로 동작합니다. 같은 컴퓨터·같은 브라우저의 다른 탭끼리만 연결되므로 기능 확인용입니다.

## 1. Supabase 프로젝트 만들기 (한 번만)
1. https://supabase.com 에 가입하고 **New project**를 만듭니다. 지역은 Northeast Asia (Seoul)을 권장합니다.
2. 프로젝트 화면의 **Connect**(또는 Project Settings → API)에서 두 값을 복사합니다.
   - Project URL (예: `https://abcd1234.supabase.co`)
   - `anon` `public` key (긴 문자열)
3. Realtime 설정에서 공개 채널 접근(Allow public access)이 켜져 있는지 확인합니다. 새 프로젝트는 기본으로 켜져 있습니다.

## 2. 앱에 연결 정보 넣기
프로젝트 폴더에 `.env.local` 파일을 만들고 (`.env.example`을 복사해도 됨) 두 값을 넣습니다.

```
VITE_SUPABASE_URL=https://abcd1234.supabase.co
VITE_SUPABASE_ANON_KEY=복사한_anon_키
```

그다음 다시 빌드합니다.

```
npm run build
```

## 3. 학생들이 접속할 주소 만들기 (GitHub Pages 자동 배포)
이 프로젝트는 GitHub 저장소 **wjvalor02-tech/imperialism-marble**에 연결되어 있습니다.
`main` 브랜치에 푸시하면 GitHub Actions가 테스트 → 빌드 → 배포를 자동으로 합니다 (1~2분).

- 주소: https://wjvalor02-tech.github.io/imperialism-marble/
- Supabase 연결 정보는 저장소 **Settings → Secrets and variables → Actions**의 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`에 들어 있습니다.
  값을 바꾸면 Actions 탭에서 **Deploy to GitHub Pages → Run workflow**로 다시 배포하세요.
- 배포 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있습니다.

## 4. 수업에서
1. 전자칠판에서 주소를 열고 **모둠모드 → 방 만들기** → 설정 → **방 만들기**. 큰 글씨로 6자리 코드가 나옵니다.
2. 학생은 각자 기기에서 같은 주소 → **방 참여하기** → 코드 입력 → 나라 선택 (모둠 이름은 선택).
   대기실 화면의 "바로 들어오는 주소"(`…?room=코드`)로 들어오면 코드가 미리 채워집니다.
3. 모둠이 다 들어오면 **게임 시작**. 빈 자리는 AI가 맡게 할 수 있습니다.
4. 게임 중에는 자기 나라 차례(또는 방어·동맹 응답)일 때만 그 기기의 버튼이 눌립니다. 다른 기기에서는 같은 창이 읽기 전용으로 보입니다.

## 연결이 끊기면
- 학생 기기를 새로고침하거나 같은 코드로 다시 들어오면 **같은 나라로 돌아옵니다**.
- 진행자 → 설정·되돌리기 → **자리**에서 그 나라를 **AI에게 맡기기**로 바꾸거나, **진행자가 대신 조작**을 켤 수 있습니다.
- 게임 중에 AI가 두던 나라는 학생이 참여 화면에서 골라 이어받을 수 있습니다.
- 선생님 기기를 새로고침하면 [이어하기] 뒤 같은 방으로 다시 열립니다.

## 참고
- 무료 Supabase 프로젝트는 일주일 동안 쓰지 않으면 일시 정지될 수 있습니다. 대시보드에서 다시 켜면 됩니다.
- `anon` 키는 공개용 키라 앱에 들어가도 괜찮습니다. 이 앱은 데이터베이스를 쓰지 않습니다.
