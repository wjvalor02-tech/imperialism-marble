## 밸런스 조정 2 — 식민화 속도 (2026-11-26)
**문제:** 30분(약 72차례) 동안 각 나라가 평균 2.3바퀴만 돌고, '내 식민지에 정확히 도착해야 개발' 조건 때문에
식민지의 58%가 확보만 한 상태로 끝남. 광산 이상은 1%. 수탈이 커지는 과정을 체험하지 못함.

**조정:**
1. **출발 통과 시 일괄 개발 (기본 켬):** 출발을 지날 때 이번 바퀴에 아직 개발하지 않은 내 식민지를 골라 각각 1단계씩 개발.
   원본 규칙("1바퀴 당 1단계씩만")과 어긋나지 않음 — '도착해야 개발'은 개발 가이드의 해석이었음.
   같은 바퀴에 그 식민지에 도착해도 다시 개발할 수는 없음. 설정 화면·관리 화면에서 끌 수 있음.
2. **0단계(확보만 한 상태) 무역대금 2 → 5만원.**

**측정 (30분 ≈ 72차례, 무작위 봇 400판):**

| 조건 | 평균 단계 | 단계 0/1/2/3/4/5 | 판당 무역대금 | 남은 현금 | 파산국 | 1위% 영·프·독·미 |
|---|---|---|---|---|---|---|
| 이전 (도착 시 개발, 0단계 2만) | 0.52 | 58/34/7/1/0/0% | 181 | 259 | 0.00 | 32·40·15·13 |
| 일괄 개발 + 0단계 2만 | 1.57 | 9/33/51/7/1/0% | 390 | 149 | 0.01 | 35·40·14·11 |
| **일괄 개발 + 0단계 5만 (채택)** | 1.58 | 9/33/51/7/1/0% | 420 | 147 | 0.01 | 37·39·14·11 |
| 일괄 개발 + 0단계 10만 | 1.60 | 8/32/53/7/1/0% | 469 | 146 | 0.01 | 38·38·14·10 |

- 0단계 10만원은 회사(15만원)와 차이가 작아 개발 동기가 줄어서 5만원을 택함.
- 참고(미적용): 주사위 2개를 함께 쓰면 광산 이상이 38%까지 나오고 파산도 생김(판당 0.15국).
  시작 자금 350만원은 승률이 고르게 됨(영·프·독·미 30·31·21·19%).
  둘 다 쓰면 1위 28·25·25·23%, 파산 0.38국.

## 조정 4 — 중국의 반식민지화 칸에서도 황금열쇠 (2026-11-27, 적용)
- 원본은 20만원 납부만. 황금열쇠 칸이 파쇼다 하나뿐이라 **납부 후 황금열쇠를 뽑도록** 변경.
- 돈이 모자라 그 자리에서 파산하면 황금열쇠는 뽑지 않음.
- 측정 (30분 ≈ 72차례, 300판): 1위 비율 영·프·독·미 **27 · 27 · 25 · 22%** (이전 30·24·22·24%), 판당 파산 0.49국 (이전 0.38).

### 검토 후 미채택 — 확보하면서 바로 1단계
'확보 + 1단계'를 한 번에 하게 하는 안을 시험함 (30분 ≈ 72차례, 봇 1000판).
1위% 영·프·독·미: 확보만 26·26·26·22 → 확보+1단계 27·26·24·23 (오차 범위). 판당 파산국 0.46 → 0.85.
승률 차이는 없지만 파산이 약 2배로 늘어, 첫 바퀴에는 확보만 하는 규칙(3번)을 유지하기로 함.

### 진행자(국제은행) 역할 — 사람 배치 없음 (선생님 결정)
원본의 진행자 겸 국제은행은 실물 보드게임에서 돈을 나눠 주고 걷는 역할이라, 웹앱에서는 자동으로 처리한다.
되돌리기·설정·수동 조정·거래 기록은 상단 [⚙ 관리]에서 열고, 학생이 건드리지 않도록 교사 PIN(기본 0000)으로 잠근다.
라이베리아 벌칙은 해당 모둠이 수행 후 직접 [완료]를 누른다.

| 기준 | 1위 영·프·독·미 | 1위 동점 | 총자산 1위와 같은 판 | 2/3 시점 선두 뒤집힘 |
|---|---|---|---|---|
| A 총자산 (현재) | 26·30·24·20% | 1% | 100% | 34% |

- 나라별 승률은 기준을 바꿔도 큰 차이 없음 (프랑스가 조금 높은 건 모든 기준 공통).

- B는 동점이 5판 중 1판꼴이라 동점 처리 규칙이 꼭 필요.

#### 파쇼다를 식민지 점수에 몇 점으로 칠까 (미적용, 2000판)
1순위 = 식민지마다 (1 + 단계), 동점이면 현금 − 대출. 파쇼다 점수만 바꿔 비교.

| 파쇼다 점수 | 전체 1위 영·프·독·미 (AI 기본) | 영국이 파쇼다를 점령한 판에서 영국 1위 (AI 기본 / 영국이 항상 점령) |
|---|---|---|
| (참고) 총자산 | 27·30·23·19% | 35% / 33% |
| 0점 | 25·33·22·20% | 16% / 15% |
| 1점 | 25·33·22·20% | 19% / 17% |
| 2점 | 26·32·22·20% | 23% / 20% |
| 3점 | 26·32·22·20% | 28% / 24% |

- 영국이 파쇼다를 점령하는 판은 12%(영국이 늘 점령하려 해도 19%)라, 전체 승률은 1%p 안팎만 움직임.
- 하지만 점령한 판에서는 차이가 큼: 0~1점이면 200만원을 내고도 1위 확률이 떨어져(15~19%) 점령이 '손해 보는 선택'이 됨. 3점이어야 평균(25%) 수준.
- 영국이 점령을 많이 할수록 프랑스 승률이 오름(30 → 36%) — 점령비 200만원이 프랑스로 가기 때문. 파쇼다 점수와는 무관.

### 조정 5 — 승리 기준: 총자산 → 식민지 점수 (선생님 결정, 적용)
- 시간 종료 시 1위 = **식민지 점수**: 식민지 1곳당 1점 + 식민화 단계마다 1점 + 파쇼다 점령 3점.
- 동점이면 **현금 − 남은 대출**이 많은 나라, 그래도 같으면 총자산.
- 이유: 나라별 승률은 그대로(오차 범위)이면서, '돈'보다 '영토와 수탈의 깊이'를 세게 되어 학습 목표 1에 맞음.
  파쇼다는 점령비 200만원이 크므로 3점이어야 점령이 손해 보는 선택이 되지 않음 (위 측정 참고).
- 수치는 `RULES.victoryScore`(gameData.ts)에서 바꿀 수 있음.

| 출발 통과 개발 | 내 식민지 중 **1곳**만 골라 1단계 (`RULES.startDevelopLimit`) | 중간안 측정 참고. 자기 식민지에 도착해 개발하는 원래 규칙도 그대로 (같은 식민지는 1바퀴 1단계) |
| 식민지 수입 | 출발을 지날 때 보유 식민지 1곳마다 10만원 (`RULES.colonyIncome`). 통행료 10만원은 그대로 냄. 파쇼다는 식민지가 아니라 수입 없음 | 수입은 통행료보다 먼저 들어옴 |
| 차례 순서 | 게임 시작 때 추첨(설정 화면, 기본 켬). 결과를 알림 창으로 보여 줌 | 나라 카드도 추첨된 순서로 표시 |
| 더블 | 주사위 2개가 같은 눈이면 차례를 마친 뒤 한 번 더 굴림 (연속 제한 없음) | 라이베리아에 도착했거나 파산하면 추가 굴림 없음. 추가 굴림도 1차례로 셈(타이머·기록) |
| 라이베리아 | 원본 '엉덩이로 이름쓰기' 대신 **주사위 더블이면 탈출**. 3번 다 실패하면 원래처럼 3턴 뒤 자유 | 탈출한 더블은 그 눈만큼 이동하고 추가 굴림 없음. 주사위 1개 설정이면 쉬기만 가능 |
| 황금열쇠 비밀 | 착취 강화·대출처럼 받은 돈으로 카드가 드러나는 기록은 '최근' 한 줄에 띄우지 않음 | 교사용 관리 화면의 거래 로그에는 남음. 보관 카드는 쓸 때 공개 |
