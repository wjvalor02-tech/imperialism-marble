# 제국주의 마블 (웹앱)

중·고등학교 세계사 '제국주의와 식민지 분할' 단원용 보드게임. 교실 전자칠판 한 대에서 모둠이 돌아가며 플레이합니다.

## 웹 주소 (자동 배포)
https://wjvalor02-tech.github.io/imperialism-marble/ — `main`에 푸시하면 1~2분 뒤 자동 반영됩니다 ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

## 학생용 접속 안내 (모둠모드)
> 칠판에 띄우거나 활동지에 붙여 쓰세요.

**준비물:** 모둠별 기기 1대 (태블릿·크롬북·휴대폰 모두 가능, 인터넷 연결 필요)

1. 인터넷 브라우저(크롬·엣지·사파리)에서 아래 주소로 들어갑니다.
   **https://wjvalor02-tech.github.io/imperialism-marble/**
   - 선생님이 알려 준 `…/?room=방코드` 주소로 들어가면 방 코드가 자동으로 채워집니다.
2. 첫 화면에서 **모둠모드 → [방 참여하기]** 를 누릅니다.
3. 칠판에 보이는 **6자리 방 코드**를 입력하고 **[참여하기]** 를 누릅니다.
4. **모둠 이름**(예: 3모둠)을 적고, 우리 모둠이 맡을 **나라**를 누릅니다. 이미 다른 모둠이 고른 나라는 고를 수 없습니다.
5. 선생님이 게임을 시작하면 자동으로 게임 화면으로 넘어갑니다. 화면 위에 **나: 영국**처럼 우리 나라가 표시됩니다.
6. 게임 중에는 **우리 나라 차례**(또는 전쟁 방어·동맹 응답)일 때만 버튼이 눌립니다. 다른 나라 차례에는 같은 화면을 보며 기다립니다.

**문제가 생기면**
- 화면이 멈추거나 연결이 끊기면 **새로고침**하세요. 같은 방 코드로 다시 들어오면 **원래 나라로 돌아옵니다.**
- 그래도 안 되면 선생님께 말씀드리세요. 선생님이 그 나라를 잠시 AI에게 맡기거나 대신 진행할 수 있습니다.
- 이름·번호 같은 개인정보는 입력하지 않습니다. 모둠 이름만 적으면 됩니다.

## 바로 실행 (인터넷 필요 없음)
`dist/index.html`을 더블클릭하면 브라우저(크롬·엣지)에서 열립니다. USB에 이 파일 하나만 복사해 가도 됩니다.
진행 상황은 그 브라우저에 자동 저장되어, 새로고침해도 [이어하기]로 계속할 수 있습니다.

## 게임 방식
| 방식 | 설명 |
|---|---|
| **싱글모드** | 학생 1명이 한 나라를 맡고 나머지 3개국은 AI와 겨룸. 인터넷 불필요 |
| **모둠모드** | 선생님 기기(전자칠판)가 방을 만들고, 학생 4개 모둠이 각자 기기로 방 코드를 입력해 참여. 온라인 설정 필요 → [docs/online-setup.md](docs/online-setup.md) |
| 한 화면 모드 | 인터넷 없이 전자칠판 한 대에서 모둠이 돌아가며 진행 |

## 개발
```
npm install
npm run dev        # http://localhost:5173
npm test           # 엔진 단위 테스트
npm run simulate   # 무작위 봇 300판 밸런스 시뮬레이션
npm run build      # dist/index.html 한 파일로 빌드
```

## 수업 운영 (45분 예시)
| 시간 | 활동 |
|---|---|
| 5분 | 동기유발, 규칙 안내, 모둠별 국가 정하기 (영국·프랑스·독일·미국) |
| 30분 | 게임 (기본 타이머 30분, 끝나면 총자산 1위 승리) |
| 10분 | 성찰 활동 화면: 실제 지배국 비교, 성찰 질문 → 모둠 발표, 인쇄/PDF 활동지 |

- **진행자(국제은행)**: 상단 [🏦 진행자] → PIN(기본 0000). 메모판, 전체 거래 로그(CSV 내보내기), 자금·식민지 수동 조정, 되돌리기(최근 10개), 타이머·규칙 설정.
- **라이베리아 벌칙**: 엉덩이로 이름쓰기를 하면 진행자가 [벌칙 완료] 버튼으로 바로 탈출시킵니다.
- 성찰 화면은 건너뛸 수 없게 되어 있습니다(게임이 착취를 미화하지 않도록).

## 규칙 요약
- 시작 자금 350만원, 주사위 2개, 출발을 지날 때마다 통행료 10만원 (원본은 500만원·주사위 1개 — 30분 수업에 맞춰 조정, 설정 화면에서 되돌릴 수 있음).
- 출발을 지날 때 내 식민지를 각각 1단계씩 개발할 수 있습니다 (설정에서 끄면 도착해야만 개발).
- 주인 없는 식민지 → 확보(선택) / 내 식민지 → 바퀴당 1단계 식민화(회사→농장→광산→광산 2개→지역 특화 시설) / 남의 식민지 → 무역대금.
- 특수칸: 에티오피아(50만원), 시암(가장 가까운 내 식민지로), 라이베리아(3턴 휴식), 중국의 반식민지화(20만원), 파쇼다 사건(영국 점령 기회 / 그 외 황금열쇠).
- 황금열쇠 10장: 전쟁·방어·매각·파괴·착취·면제·동맹·대출.
- 자세한 규칙: `docs/rules.md`, 해석한 부분: `docs/rule-decisions.md`.
